Verification repair (market-living)

What happened

Matt asked why the two done items looked out of scope or off-spec. They were.

market-living's done_when was "at least 20 named operators, each with price and a scale signal". The file had 52 operators and 84 guessed numbers marked "(unverified)". The count passed; the evidence did not.

Root cause — proven from transcripts, not guessed

Two stacked failures (full dig: data/postmortem-market-research.md):

  1. The prompt offered an escape hatch. It paraphrased the Amazon recipe from source-access.md and told subagents they could "mark unverified". They did. The market-dead prompts, written by the same agent an hour later, said "read source-access.md first" and "do NOT invent examples" — that file has 1 hedge against 84.
  2. No verification gate. The main agent merged four scratch files and flipped QUEUE.json to done in one Bash command. No grep, no read of done_when. market-dead had a dedicated merge agent told to drop unverified rows; market-living had none.

The trigger was money, not a blocked source. The round blew the $2.00 cap ($2.0049, error_max_budget_usd). One subagent wrote: "Budget is nearly exhausted ($0.48 left). Writing findings now with what's verified." The cap has since been removed.

What we tried and abandoned

Matt's hypothesis: Amazon blocks cold deep links, warm navigation works. Refuted (data/amazon-access-probe.md). Seven consecutive cold deep links, no wall, no captcha, no rate limit. Cookie freshness on disk is what matters, not per-session warm-up. The subagents never called rb at all — they pre-loaded only WebSearch/WebFetch, so they never tested the barrier they did not hit.

The repair

Three Sonnet passes refetched every number live. competitors-living.md now has 51 operators, 9/9 QA spot-checks matched live sources, QA verdict PASS (data/qa-competitors-living.md). Six real errors corrected:

  • Why Nations Fail Goodreads: 7 → 66,920 (old fetch hit an empty edition)
  • Prisoners of Geography: 806 → 124,346 (same bug)
  • Sapiens "paperback $14.99" was the Kindle price; paperback is $19.08
  • Curiosity Stream "~$20-40/yr" → $49.99-79.99/yr
  • Factfulness was missing — 15 trad titles, not the 14 claimed
  • History for Busy People is an imprint operator, not a single title

Killed a fabrication that had already reached Matt: the "newsletters $5/mo or $50/yr" norm. Substack paid tiers are not publicly visible at all — every /subscribe page shows only a free email box. Subscriber counts are visible though (15,000-203,000), and are the better scale signal.

New operational constraint

rb is one shared Chrome daemon. Parallel subagents hijack each other's navigation — caught live this session, one agent mid-flight on another's page. One browser subagent per round, or clone the profile into an isolated session. Always confirm the URL that loaded before trusting scraped text; a silent hijack looks exactly like real data.

Scope violation, separately

A round started demand while it was todo. todo means Matt has not asked. The round was killed before anything was written; a later round self-reverted it. docs/sessions/2026-08-27-demand-evidence.md now carries a CORRECTION block — none of the work it describes exists.

Docs made false and rewritten

  • docs/notes/source-access.md — Amazon section rewritten (no warm-up needed), browser-contention and Substack-price sections added.
  • docs/working-mode.md — new "Delegating research" rules; cost section corrected (cap removed).
  • DECISIONS.md — verification decision logged with rejected alternatives.

Where things stand

market-living and market-dead are genuinely done. Everything else is todo and stays there until Matt's words make it active. Next in his stated order: demand → money → angle.
